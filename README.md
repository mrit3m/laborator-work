### Локальный запуск проекта (если есть код)

   ```bash

   ```
2. Перейдите в папку проекта:
   ```bash
   cd project-name
   ```
3. Откройте файл `index.html` в браузере *(или выполните установку зависимостей: `npm install && npm start`)*.
